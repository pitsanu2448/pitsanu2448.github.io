RAG (Lewis et al., 2020)

Chain-of-Thought (Wei et al., 2022)

LoRA → DoRA → RSLoRA

5

Medical RAG (Peng et al., 2023)

RAG ในบริบทการแพทย์ลด Hallucination อย่างมีนัยสำคัญ — ยืนยันแนวทางของงานวิจัยนี้

Research Objectives
1

พัฒนา RAG + CoT สำหรับการแพทย์ไทย

ใช้ RAG เพิ่มความถูกต้องและลด Hallucination ร่วมกับ Chain-of-Thought ส่งเสริมการให้เหตุผลเชิงตรรกะในการวิเคราะห์อาการและให้คำแนะนำทางการแพทย์

2

Fine-tune Thai Medical LLM เฉพาะด้าน

Fine-tune โมเดลที่เหมาะสม (chinda-qwen3-4b, THaLLE-8B, typhoon2.5) ด้วยข้อมูลทางการแพทย์ภาษาไทยคุณภาพสูง แปลจากแหล่งข้อมูลระดับนานาชาติ

3

สร้างระบบ Triage เบื้องต้น 4 ระดับ

ประเมินความเร่งด่วน Critical / High / Medium / Low เพื่อกรองผู้ป่วยและลดความแออัดในโรงพยาบาล ลดภาระแพทย์

4

พัฒนาระบบ Multimodal ครบวงจร

รองรับ Input ทั้งข้อความ ภาพทางการแพทย์ (ViT/BLIP) และเสียง (Whisper) เพื่อการวินิจฉัยเบื้องต้นที่ครอบคลุม

ออกแบบ UI ที่ใช้งานง่ายและ PDPA-compliant

Data Collection & Preprocessing

Fine-tuning: DoRA+RSLoRA+4-bit NF4

Hybrid RAG Construction

Agentic CoT Pipeline

Linear CoT (ทั่วไป) → Tree-of-Thoughts 3 สมมติฐาน (วินิจฉัยแยกโรค) → PAL (คำนวณยา mg/kg) + Safety Reflection Loop (DANGER_PHRASES)

RAGAS + BERTScore Evaluation

ประเมิน Faithfulness, Answer Relevancy, Context Recall, Context Precision + BERTScore F1, P, R + ROUGE-L + Perplexity

Analysis & Discussion

✅ จุดแข็ง (Strengths)

BERTScore F1 = 0.6768 — ยืนยันว่า Fine-tuning ด้วยข้อมูลไทยเพิ่ม Semantic Similarity อย่างมีนัยสำคัญ เทียบ Baseline typhoon2.5 (0.6637)
Hybrid RAG ลด Hallucination — การรวม FAISS+BM25+RRF ให้ Recall สูงกว่า Single-retriever พิสูจน์ตาม Cormack et al. (2009)
Agentic CoT เลือก Strategy อัตโนมัติ — Linear/ToT/PAL ตรงกับประเภทคำถาม ทำให้ Reasoning โปร่งใสและตรวจสอบได้ + Safety Reflection Loop ป้องกันข้อมูลอันตราย
Edge-deployable — ขนาด 4B params + 4-bit quant ทำงานบนฮาร์ดแวร์ประหยัดได้ ไม่ต้องส่งข้อมูลขึ้น Cloud เหมาะ PDPA

⚠️ ข้อจำกัดและโอกาสพัฒนา

Perplexity = 10,000 (ทุกโมเดล) — สูงกว่าเกณฑ์ ≤ 20 มาก แสดงว่า Generation ยังไม่เสถียร ยังไม่พร้อมเชิงพาณิชย์
ROUGE-L ของ chinda ต่ำ (0.10) — Fine-tuning เพิ่ม Semantic แต่ลด Lexical Overlap อาจเป็น Style Shift จากการ Instruction-tuning
ชุดข้อมูล 800 records ยังน้อย — ต้องเพิ่ม Medical Corpus ภาษาไทยจาก ICD-10, Thai Clinical Guidelines และ Clinician-validated Q&A
ต้องทดสอบกับผู้ใช้จริง — Clinician Validation, Usability Test กับผู้ป่วยจริงในสภาพแวดล้อมโรงพยาบาล (SRL 3 → 5)
💡 Honest Assessment: Perplexity = 10,000 → ยังไม่พร้อมเชิงพาณิชย์ · ต้องเพิ่ม training data · ทดสอบกับ clinician จริง · SRL 3→5 · แต่ BERTScore F1 ที่ 0.6768 แสดงศักยภาพที่ชัดเจนว่า Fine-tuning ด้านภาษาไทยทางการแพทย์ได้ผล
