📄 บทคัดย่อ (Abstract)

การศึกษาครั้งนี้วิเคราะห์โครงสร้างและความเหลื่อมล้ำของรายได้ครัวเรือนไทย ปี 2566 โดยใช้ข้อมูล NSO จำนวน 6,829 ครัวเรือน 77 จังหวัด ผสานเทคนิค Data Storytelling (Python, Pandas, Plotly) กับระบบ RAG บนโมเดล Typhoon2.5-Qwen3-4b (4-bit quantization) เพื่อตอบคำถามเชิงนโยบายแบบโต้ตอบ ผลพบว่ารายได้เฉลี่ย 26,279 บาท/เดือน ช่องว่างรายได้สูงสุด-ต่ำสุด 40.7 เท่า ความเหลื่อมล้ำรุนแรงในกลุ่มอาชีพ (Gap 3.1×) และระดับจังหวัด (CV สูงสุด 0.801) ระบบ AI ตอบคำถามได้ BERTScore F1 = 0.7928 นำเสนอนวัตกรรมด้านการวิเคราะห์ข้อมูลสาธารณะสำหรับผู้กำหนดนโยบาย

  • 3
    Retrieval-Augmented Generation (RAG) — เพิ่มความแม่นยำของ LLM โดยดึงเอกสารจาก Knowledge Base แบบ Real-time ก่อนสร้างคำตอบ

Novelty & System Architecture

🤖 Thai LLM ท้องถิ่น

ใช้ Typhoon2.5-Qwen3-4b รันบน GPU vRAM 8GB+ ด้วย 4-bit quantization ไม่ต้องพึ่งพา Cloud API ประหยัดต้นทุน ข้อมูลไม่รั่วไหล

4กระบวนการสร้างสรรค์ (Methodology)

วิธีการ เทคนิค เครื่องมือ และขั้นตอนการทำงาน

🗂️ ขั้นตอนที่ 1–3: Data Pipeline
  • 1
    Data Collection — ดาวน์โหลดชุดข้อมูลรายได้ครัวเรือนจาก Open Data สำนักงานสถิติแห่งชาติ (NSO) ปี 2566 จำนวน 7,700 รายการ ครอบคลุม 77 จังหวัด
  • 2
    Data Cleaning (Pandas) — จัดการค่า Missing, Outlier และ ลด Noise เหลือ 6,829 รายการ แปลง feature กลุ่มอาชีพ ภาค และจังหวัดให้ถูกต้องครบถ้วน
  • 3
    Feature Engineering — คำนวณ KPI: Mean, Median, P10, P90, P99, CV (Coefficient of Variation), Max/Min Ratio, Deviation จากค่าเฉลี่ยประเทศ
ภาพที่ 4: Deviation รายได้เทียบค่าเฉลี่ยประเทศ ตามกลุ่มอาชีพ
🤖 ขั้นตอนที่ 4–6: AI System
  • 4
    Knowledge Base Construction — แปลงข้อมูลครัวเรือนทุกแถวเป็นเอกสารข้อความ 6,829 docs Embed ด้วย BGE-M3 บันทึกใน ChromaDB (Vector Store)
  • 5
    Hybrid RAG Pipeline — Dense Retrieval (Cosine Similarity) + BM25 Sparse Retrieval รวมผล Reciprocal Rank Fusion (RRF) ดึง Top-10 เอกสาร
  • 6
    LLM Generation & Evaluation — Typhoon2.5-Qwen3-4b สร้างคำตอบจาก Context วัด BERTScore F1 บน 51 คู่ถาม-ตอบ (Gold Standard)

ระบบ AI (Typhoon2.5-Qwen3-4b + Hybrid RAG) ตอบคำถามเชิงนโยบายได้แม่นยำ โดยดึงหลักฐานจาก Knowledge Base 6,829 เอกสาร:

❓ จังหวัดใดมีความเหลื่อมล้ำสูงสุด?

❓ นโยบายลดความเหลื่อมล้ำภาคเกษตร?
✅ สนับสนุนรายได้โดยตรง ประกันรายได้ เกษตรรวมกลุ่ม (ถูกต้อง)

📐 ข้อค้นพบสำคัญ & การตีความ
🔴 ค้นพบ 1: ความเหลื่อมล้ำเชิงอาชีพ (Gap 3.1×)
รายได้ผู้จัดการ/วิชาชีพ (48,293 บาท) สูงกว่าคนงานเกษตร (15,804 บาท) ถึง 3.1 เท่า สอดคล้องกับ Human Capital Theory — การศึกษาและทักษะกำหนดรายได้อย่างมีนัยสำคัญ
🟡 ค้นพบ 2: ความเหลื่อมล้ำเชิงภูมิภาค (CV สูงสุด 0.801)
จังหวัดรายได้สูง ≠ CV ต่ำ — กรุงเทพฯ มีรายได้สูงแต่ CV = 0.746 (เหลื่อมล้ำสูง) ขณะที่นราธิวาสมีรายได้ต่ำสุดและ CV สูงพร้อมกัน
🟢 ค้นพบ 3: โครงสร้างรายได้เปราะบาง
ทุกกลุ่มอาชีพพึ่งรายได้ประจำ 27–30% ของรายได้รวม รายได้ไม่ประจำ <1% ขัดกับสมมติฐานที่คาดว่าเกษตรกรพึ่งรายได้ไม่ประจำสูง → ชี้ว่าครัวเรือนไทยยังมีความเปราะบางสูงหากรายได้ประจำหยุด
